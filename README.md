# Kalyanam - Premium Wedding Card Distribution Management System

Kalyanam is an enterprise-grade Wedding Card Distribution Management System featuring a traditional, luxurious Indian wedding card theme. Built using Next.js 15 (App Router, Tailwind CSS, TypeScript, and Framer Motion), it relies on Supabase for Serverless Backend services (authentication, PostgreSQL, role mappings) and Zustand for React state management. Optimized and configured for direct deployment to Netlify.

---

## 1. System Features

*   **Premium Visual Design**: 3D wax-sealed letter-opening cards, canvas floral particle flows, and gold foil text gradients.
*   **Supabase Serverless Core**: Integrated Supabase Auth (Email password and Google OAuth login), protected routing checks, and PostgreSQL row-level security.
*   **React Hook Form & Zod**: Validates mobile phone structures, pincodes, and address forms prior to database inserts.
*   **Traveling Salesperson Route Planning**: Groups guest vectors by city and area, computing traveling salesman paths and route lines on maps.
*   **PWA Installable App**: Offline service workers and manifest bindings for mobile home screen installations.
*   **Bulk Sheet Exchanges**: Import and export guest registries to and from Excel spreadsheets using SheetJS.

## 2. Supabase Database Configuration

Copy and execute these SQL commands in the **SQL Editor** of your Supabase project to build database schemas:

```sql
-- Create Users Table (Associated with auth.users)
CREATE TABLE public.users (
    id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    role VARCHAR(20) DEFAULT 'Distributor' CHECK (role IN ('Admin', 'Distributor')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Read Authenticated" ON public.users FOR SELECT TO authenticated USING (true);
CREATE POLICY "Self Update" ON public.users FOR UPDATE USING (auth.uid() = id);

-- Create Guests Table
CREATE TABLE public.guests (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    phone VARCHAR(15) NOT NULL,
    address TEXT NOT NULL,
    village VARCHAR(100) NOT NULL,
    city VARCHAR(100) NOT NULL,
    state VARCHAR(50) DEFAULT 'Andhra Pradesh' NOT NULL,
    pincode VARCHAR(10) NOT NULL,
    latitude DECIMAL(10, 8),
    longitude DECIMAL(11, 8),
    notes TEXT,
    status VARCHAR(20) DEFAULT 'Pending' CHECK (status IN ('Pending', 'Assigned', 'Distributed')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

ALTER TABLE public.guests ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Read Authenticated" ON public.guests FOR SELECT TO authenticated USING (true);
CREATE POLICY "Admin All Access" ON public.guests FOR ALL TO authenticated USING (
    EXISTS (
        SELECT 1 FROM public.users 
        WHERE public.users.id = auth.uid() AND public.users.role = 'Admin'
    )
);
CREATE POLICY "Distributor Update Status" ON public.guests FOR UPDATE TO authenticated USING (true);

-- Create Distributions Table
CREATE TABLE public.distributions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    guest_id BIGINT REFERENCES public.guests(id) ON DELETE CASCADE,
    assigned_to UUID REFERENCES public.users(id) ON DELETE SET NULL,
    assigned_date DATE DEFAULT CURRENT_DATE,
    delivered_date DATE,
    remarks TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

ALTER TABLE public.distributions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Read Distributions Authenticated" ON public.distributions FOR SELECT TO authenticated USING (true);
CREATE POLICY "Write Distributions Authenticated" ON public.distributions FOR ALL TO authenticated USING (true);
```

## 3. Local Setup & Execution

Once Node.js and npm are installed in your command path:

1.  **Clone or Copy Project**: Navigate to the directory containing `package.json`.
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Configure Environment**:
    Create a `.env.local` file in the root directory:
    ```env
    NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anonymous-anon-key
    NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your-google-maps-api-key
    ```
4.  **Launch Local Development Server**:
    ```bash
    npm run dev
    ```
    Open `http://localhost:3000` in your web browser.

## 4. Netlify Deployment Guide

Netlify fully integrates with Next.js 15 App Router websites.

1.  **Connect Git Repository**: Commit your files and push to a Git provider (GitHub, GitLab, Bitbucket).
2.  **Create Netlify Project**: Import your repository in the Netlify Dashboard.
3.  **Build Settings**:
    *   **Build command**: `npm run build`
    *   **Publish directory**: `.next`
    *   Netlify will automatically detect and configure the Next.js runtime plugin based on our `netlify.toml` mappings.
4.  **Set Environment Variables**:
    In Netlify project settings, add the environment variables specified in Section 3 under **Site configuration** > **Environment variables**.
5.  **Trigger Deploy**: Netlify will compile your site, package edge routes, and host it globally.
